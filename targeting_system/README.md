# Hedef tespit ve hizalama

Laptop üzerinde çalışacak Python yazılımını bu klasörde geliştirin.

Bu bölüm kamera görüntüsünün alınmasını, YOLO tespitlerini, görüntü merkezine göre hedef konumunun hesaplanmasını, arama/hizalama davranışını ve UART haberleşmesini kapsar. Başlangıçta ve hedef kaybında arama moduna geçişi burada yönetin.

Çalıştırma komutlarını, Python bağımlılıklarını, kamera/seri port ayarlarını ve hata davranışlarını kendi uygulamanızla birlikte belgeleyin. Bu başlangıç reposunda çözüm kodu veya eğitilmiş model bulunmaz.
