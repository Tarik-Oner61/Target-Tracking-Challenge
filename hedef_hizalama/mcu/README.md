# Arduino UNO motor kontrolü

Arduino UNO üzerinde çalışacak UART ve STEP/DIR motor kontrol yazılımını bu klasörde geliştirin. Programlama dili serbesttir.

Yaw/pitch eksenleri için pin bağlantılarını, kullanılan step sürücülerini, seri haberleşme protokolünü, yükleme adımlarını ve durdurma/hata davranışlarını kendi donanımınızla birlikte belgeleyin. Motor sürücüsü ve pin düzeni bu başlangıç reposunda belirlenmemiştir.
