# Sağlanan drone veri setleri

Bu görev için veri setleri tarafımızdan sağlanmaktadır. Adaylardan ayrıca veri seti araştırmaları beklenmemektedir.

1. [Drone veri seti 1 — PARS Dataset V2](https://universe.roboflow.com/new-workspace-maa2l/pars-dataset-v2/browse?queryText=class%3ADrone&pageSize=100&startingIndex=1100&browseQuery=true)
2. [Drone veri seti 2 — PARS](https://universe.roboflow.com/hasans-workspace-lnuhg/pars-9yaon/browse?queryText=class%3ADrone&pageSize=100&startingIndex=100&browseQuery=true)

Bu bağlantılar `Drone` sınıfı filtresi ve sayfalama parametreleri içeren Roboflow gözatma bağlantılarıdır. Veri seti dosyaları bu başlangıç reposuna kopyalanmamıştır.

Eğitim çalışmanızla birlikte aşağıdaki bilgileri bu klasörde belgeleyin:

- Kullanılan veri seti bağlantısı ve sürümü.
- Veri setinin kullanım/lisans bilgileri ve sınıfları.
- Eğitim, doğrulama ve test bölünmesi.
- Uygulanan veri hazırlama ve varsa artırma işlemleri.

Eğitim sonuçlarını `../results/`, eğitilmiş model dosyasını `../models/` altında teslim edin. Repo kökündeki [hedef-drone.jpeg](../../../hedef-drone.jpeg) hedef referans fotoğrafıdır.
